## 一、设计意图复盘

spec-03 是 q5 章里信息密度最高的一份：月度分布、胜率陷阱、TopNRanking 2021 个案、回撤事件、水下曲线，全都集中在这一节。它要教的其实是两个高价值认知：**胜率不是收益**，以及**回撤不是一个数字，而是一段时间体验**。【动机】【教学场景】

**为什么用月度而不是日度**：日度太碎，噪声太多；年度又太粗，容易把很多痛苦的月份揉平。月度是“统计可看”和“体验可感”之间的甜蜜点。虽然 spec 没专门写一段解释这个取舍，但当前结构已经能让学员自然感受到这个尺度的合理性。

**胜率陷阱的教学路径仍然很强**：先看整体胜率，再看 2021 年年度亏损，最后落到 2021 年月度盈亏比。这个三层递进设计是本节最亮的地方，因为它不是靠一句“别迷信高胜率”说服学员，而是让数据一步步反驳直觉。

**当前版本的关键修补**有四处：前提检查写显式；月收益 = 0 的口径写显式；回撤阈值 `THRESHOLD = -0.001` 写显式；回撤与胜率的机械断言写进验证段。这让本节从“讲得很好”向“跑得更稳”前进了一大步。

**当前最大的剩余问题**仍然是容量：它依旧是一份很重的 spec。即便已经更精确了，LLM 和学员都仍需要在一个单元里切换多个分析视角，这就是本节最大的真实代价。【简洁】

## 四、可改进点

### 改进 1：如果追求执行稳定性，优先拆轻【简洁】

**现状**：单份 spec 同时承载月度分布、2021 个案、回撤事件和水下曲线。

**改写**：
```markdown
spec-03a: 月度分布 + 2021 案例
spec-03b: 回撤事件 + 水下曲线
```

**为什么**：这不是因为当前 spec 错了，而是因为它已经接近“单份 spec 的上限”。拆开会提升 LLM 执行稳定性，也会让学员更容易跟得上。

### 改进 2：把结果沉淀为结构化变量【输出契约】

**现状**：当前 spec 主要定义了展示形态，但没有硬性要求 `monthly_stats_df`、`drawdown_summary_df` 这类变量。

**改写**：
```markdown
4. 打印月度统计对比表：
   - 先构造 `monthly_stats_df`
7. 打印回撤汇总：
   - 先构造 `drawdown_summary_df`
```

**为什么**：结构化变量会让后续 insight、review 或书稿摘录更容易复用，而不必从 print 文本回收。

### 改进 3：把前提检查代码块也标准化【可复现】

**现状**：文字上要求检查 `results` / `RESULT_COLORS` / `eq_bh_portfolio`，但没有直接给代码片段。

**改写**：
```python
required = ["results", "RESULT_COLORS", "eq_bh_portfolio"]
missing = [name for name in required if name not in globals()]
assert not missing, f"缺少前置变量: {missing}"
```

**为什么**：这会让“接续型 spec”真正具备可复制的防呆入口。

## 五、可沉淀的方法点

### A. 这份 spec 已经示范的原则

- **【动机】用数据逐层揭穿“高胜率 = 好策略”**：这是很强的反直觉教学设计。
- **【教学场景】回撤的双维度教学**：不只讲深度，还讲恢复时间，把数字还原成持有体验。
- **【精确】阈值与边界口径必须显式**：`THRESHOLD = -0.001` 和“0 收益归亏损月”都是好示范。
- **【正向】动态描述方向，避免模板化结论**：继续保持了 q5 章的一致风格。

### B. 当前版本最值得继续沉淀的原则

- **【验证】回撤不变量（始终 <= 0）是很好的课程级断言模板**。
- **【同步】跨 spec 的颜色继承非常重要**：这是学员建立视觉记忆的关键。
- **【接续型】重度分析 spec 必须显式声明对上游 notebook 状态的依赖**。

### C. 领域/教学场景特殊考量

- **【教学场景】胜率陷阱是量化教育里最值得早点打掉的直觉偏误之一**。
- **【教学场景】回撤事件化思维能把抽象统计量变成具体可感的经历**。
- **【教学场景】2021 这种具体年份案例，比抽象地说“某些年份”有效得多**。
