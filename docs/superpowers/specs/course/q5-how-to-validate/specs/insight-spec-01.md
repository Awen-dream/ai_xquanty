## 一、设计意图复盘

这是 q5 的开篇 spec，承担**给“好不好”装一把尺子**的核心教学任务。前四章学员一路看到“年化 15%、夏普 0.8”这类数字，但从未问过这些数字“贵不贵”——本章的破冰就是把“等权买入持有三只 ETF”这个朴素基准摆到对比表的最后一行，让数字第一次有了参照物。【动机】【教学场景】

**为什么选四个策略一起对比**：EqualWeight、RiskParity、TopNRanking、RP+止损 5%——这是 Q3-Q4 全部“产出物”的合集。spec 不引入新的策略，而是把前四章的产出**集中送进体检台**。这个选择依然很克制：学员认知负担只在“评估方法”这一条线上，不需要再消化新的策略逻辑。【教学场景：渐进难度】

**为什么用三把尺子（夏普/卡玛/索提诺）而不是只夏普**：本节的二级教学目标是建立“风险有多个维度”的认知。spec 在要求 2 列出三个比率的接口，并在分析段明确“夏普看总波动、卡玛看最大回撤、索提诺看下行波动”——这是把概念锚定到评估接口和风险语义上，而不是停留在词汇层。【动机】

**当前版本最重要的修补**有三处：一是把固定时间窗、排他下载边界、兼容 broker 写死；二是把 `results`、`eq_bh_portfolio`、`RESULT_COLORS` 这些后续 spec 依赖的变量契约写显式；三是收紧 `RP+止损5%` 的表达，明确它复用 `RP_PORTFOLIO`，不是第二个 optimizer。这三处直接提升了【可复现】【同步】【接续型 spec】三个维度。

**当前仍有的克制点与张力**：spec 依然没有把三把尺子的完整计算口径显式化，也没有锁定 open-xquant 版本。这样做保持了对框架实现的低耦合，但代价是“跨版本对账”仍不够刚性。【精确】

## 四、可改进点（带改写示例）

### 改进 1：锁定版本与指标口径【可复现】【精确】

**现状**：spec 锁了时间窗和 broker 语义，但没有锁 open-xquant 版本，也没有明确年化和风险比率的计算口径。

**改写**：
```markdown
0. 版本与口径约定：
   - open-xquant >= 0.4.0
   - 年化按 252 个交易日
   - 夏普比默认无风险利率为 0
   - 基准的夏普比沿用与 `RunResult.sharpe_ratio()` 相同口径
```

**为什么**：当前剩余的不确定性主要来自“同一份 spec 在不同库版本下是否还能对齐”。把版本与口径补上，q5 的数字就更像“数据快照”，更适合跨时间复用。

### 改进 2：把结构化输出变量从“建议”升级为“要求”【输出契约】

**现状**：验证段建议使用 `comparison_df` 和 `alpha_df`，但没有把它们定义为强契约。

**改写**：
```markdown
10. 打印策略 vs 基准对比表：
   - 先构造 `comparison_df`
   - 再构造 `alpha_df`
   - print 只是展示层，后续 spec 复用这两个变量
```

**为什么**：一旦后续 spec 或 review 文档要复用这些结果，结构化变量会比 print 文本稳得多。

### 改进 3：给验证段增加一条“基准指标合理区间”断言【验证】

**现状**：当前验证已经有 shape 和容差，但基准值域仍主要依靠人工判断。

**改写**：
```markdown
- `assert -0.6 < bh_max_dd < 0`
- `assert bh_vol > 0`
- `assert not eq_bh_portfolio.empty`
```

**为什么**：这些断言不会让 spec 变重太多，却能更快暴露数据缺口或基准构造错误。

## 五、可沉淀的方法点

### A. 这份 spec 已经示范的原则

- **【动机】把“为什么用这把尺子”写进 spec**：三把尺子不是装饰指标，而是风险维度的教学入口。
- **【教学场景：open-xquant 框架】先读后写双层指示**：先读 `RunResult`，再读 optimizer，输入输出契约都覆盖到了。
- **【结构】把基准与策略放进同一张表**：视觉锚点非常强，学员很容易理解“比较”的意义。
- **【接续型】把 `results`、`eq_bh_portfolio`、`RESULT_COLORS` 显式定义为可复用状态**：这次修补后，q5 四份 spec 的链式执行明显更稳。
- **【正向】动态描述方向，避免硬写“更高/更低”**：对 LLM 很友好，也直接减少幻觉式分析。

### B. 当前版本最值得继续沉淀的原则

- **【同步】概念去重比补代码更重要**：`RP+止损5%` 复用 `RP_PORTFOLIO` 这件事看似小，实际减少了教学噪声。
- **【验证】shape 断言 + 容差断言是很好的课程级 compromise**：既不需要过度形式化，又比“看着像对”强得多。
- **【接续型】后续章节依赖的变量名应在第一份 spec 就写死**：这是 q5 当前最值得复用的模板经验之一。

### C. 领域/教学场景特殊考量

- **【教学场景】量化指标的年化口径是行业默契，但零基础课程里必须逐步显式化**。
- **【教学场景】“等权买入持有”作为基准，比直接引入外部大盘指数更容易被初学者理解**。
- **【教学场景】框架类课程比通用 prompt 更依赖“读源码再写代码”**：这在 q5 这里体现得很完整。
