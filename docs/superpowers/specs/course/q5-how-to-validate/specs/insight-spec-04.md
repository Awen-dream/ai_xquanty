## 一、设计意图复盘

spec-04 是 q5 章的收尾——回答最后一个体检维度：**好策略不怕参数变**。这是 q5 整章最具方法论意义的认知升级：不只看单点数字，还看“参数附近的形状”——是高原（plateau）还是山峰（peak）。【动机】

**与 q1/spec-06 参数扫描的关键区别**现在已经写清楚了：q1 是“用扫描找最优参数”，q5/spec-04 是“用扫描判稳健性”。这是本轮修补里最重要的提升之一，因为它把“同样的技术，不同的教学目的”明确写进了 spec，而不是留给学员自己猜。【动机】

**为什么扫描这三个维度（vol_period / mom_period / stop_loss）**：它们都是前面三步已经用过的参数。spec-04 继续保持 q5 章的一贯克制：不引入新对象，只拿已经出现过的对象做体检。

**高原型 vs 山峰型的隐喻设计**依然很强。“想象你在山上找营地”这句，不只是文学修辞，而是把一个很抽象的稳健性概念翻译成零基础学员立刻能懂的空间直觉。它是当前版本里最值得保留的教学表达之一。

**当前版本的关键修补**还有三处：前提检查显式化；“无止损”要求作为表格最后一行统一展示；验证段增加了长度断言和 `rp_range < tnr_range` 的机械检查。它们让本节从“讲得清楚”升级到了“也更容易跑对”。

## 四、可改进点

### 改进 1：解释扫描点为什么这样取【可复现】【动机】

**现状**：`[10, 15, 20, 25, 30, 40]` 是合理列表，但 spec 没解释它的设计逻辑。

**改写**：
```markdown
- 中心值 20 是前文主参数
- 15/25、10/30 是近邻扰动
- 40 是远端外推
- 不取 5，是为了避免过短窗口失去稳定性
```

**为什么**：这会让学员明白“扫描不是乱试参数”，而是在围绕既有结论做稳健性检验。

### 改进 2：把“无止损最后一行”同步到 notebook 实现【同步】

**现状**：spec 已经要求统一 8 行表，但 notebook 还是“7 行表 + 1 行单独 print”。

**改写**：
```markdown
4. 止损阈值敏感性：
   - 先构造统一表格 DataFrame
   - 最后一行填“无止损”
```

**为什么**：当前最大的同步差异并不在分析逻辑，而在展示 contract。补掉这个差异，spec 与 notebook 的一致性会明显更高。

### 改进 3：给“高原 vs 山峰”的结论加显著性下界【验证】

**现状**：当前已经有 `rp_range < tnr_range`，但还没有“差多少才有教学说服力”的阈值。

**改写**：
```markdown
- `assert tnr_range >= rp_range * 1.5`
```

**为什么**：这会让“高原”和“山峰”的差异不只成立，而且足够明显，避免出现“虽然更大，但肉眼根本看不出差别”的教学尴尬。

## 五、可沉淀的方法点

### A. 这份 spec 已经示范的原则

- **【动机】同一技术在不同章节承担不同教学角色时，必须显式区分**。
- **【精确】统一 y 轴范围是比较型图表的关键决策**。
- **【动机】“无止损”作为极端基线进入同一对比框架，很有教学力量**。
- **【正向】动态描述方向，继续保持了 q5 章的防幻觉风格**。
- **【验证】用 `rp_range < tnr_range` 把视觉结论转成可机械检查的结论，非常值得复用**。

### B. 当前版本最值得继续沉淀的原则

- **【教学】“高原型 vs 山峰型”是非常适合零基础课程的原创隐喻**。
- **【验证】形状类结论最好同时有图和数字两条证据链**。
- **【同步】展示层 contract 也值得被当成一等公民看待**：不只是“算对”，还要“展示一致”。

### C. 领域/教学场景特殊考量

- **【教学场景】参数扫描不是只有“找最优”一种用途**：q5 很好地展示了它的第二面——判稳健性。
- **【教学场景】把稳健性翻译成空间隐喻，比直接讲统计术语更适合零基础读者**。
- **【教学场景】夏普比极差把“图上看起来平/尖”转成一个数字，是很好的双通道教学动作**。
